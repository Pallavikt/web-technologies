Internet

    A massive, global physical network connecting millions of computers, routers, and devices to exchange data using the Internet Protocol (IP).

    Server

    A high-powered computer or software system that stores data and "serves" files, services, or functionality to other client computers across a network.

    Host

    Any computer, device, or specialized server connected to a network that acts as a storage point to make websites, applications, or data accessible to users.

    Web

    Short for the World Wide Web (WWW). It is an information system built on top of the physical internet, allowing documents and multimedia to be linked and accessed via URLs using web browsers.

    Web Technology

    The collective suite of tools, programming languages, protocols, and software platforms (like HTML, HTTP, and databases) used to build and operate the World Wide Web.

    Web Application

    An interactive software program that runs on a remote server and is accessed dynamically through a web browser (e.g., Google Docs, online banking, or social media networks).

    Website

    structured, public collection of related, interlinked web pages hosted under a single domain name (e.g., google.com).

    Web Page

    single digital document on a website that can contain text, images, videos, and hyperlinks, rendered for display by a web browser.

    HTML

    Stands for HyperText Markup Language. It is the foundational code framework used to structure a web page by defining elements like headings, paragraphs, and links.

    CSS

    Stands for Cascading Style Sheets. It is a design language used to style the visual presentation of HTML code, controlling elements like fonts, colors, layout grids, and responsive behavior across screen sizes.
